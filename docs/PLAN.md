## 一、项目目标

打造一套**个人 AI 操作系统（Personal AI OS）**：

- 个人数据默认存储在自己的电脑或服务器上（本地优先）。
- 云端大模型负责理解、推理和规划。
- AI 逐步了解你的习惯、项目、目标和历史决策，并基于真实数据给出建议。
- 涉及修改文件、发送消息、执行命令等操作时，**必须先由用户确认**。

**核心原则**：大模型负责理解和推理，数据库负责保存事实，业务代码负责权限与执行。不能让大模型凭对话印象决定所有事情，也不能让模型绕过审批直接操作电脑。

## 二、总体架构

```
个人 AI Web 工作台（前端）
        │  HTTPS / REST API / 流式响应
Python AI 后端（FastAPI）
        │
        ├── 记忆管理：提取、检索、纠错
        ├── 知识库 RAG：文档解析、引用
        ├── 个人分析：目标、习惯、趋势
        └── 工具与审批：提议、确认、执行
                │
        本地数据层（SQLite → PostgreSQL + pgvector）
        档案、记忆、对话、向量索引、审批记录
                │
        本地文件层：原始文档 + 备份（PDF、Markdown、Word、项目文档）
                │
        云端大模型 API（按需发送必要上下文，不默认上传全部个人资料）
```

## 三、技术栈（MVP → 演进）

| 模块 | MVP 选型 | 作用 | 后续演进 |
| --- | --- | --- | --- |
| 前端 | HTML + CSS + JavaScript | 快速交付可操作界面 | Vue 3 + TypeScript |
| 后端 | Python + FastAPI | API、记忆检索、AI 调用和权限管理 | — |
| 本地数据库 | SQLite | 无需单独安装数据库 | PostgreSQL + pgvector + 全文检索 |
| 云端模型 | OpenAI 兼容 API | 推理、总结和个性化建议 | — |
| 文档检索 | 关键词匹配 | 基础检索 | PDF/DOCX/MD 解析与分块、向量检索 |
| 自动化 | 审批记录工作流 | 先确认，再考虑执行 | LangGraph / 原生工具调用工作流 |
| 测试 | pytest + FastAPI TestClient | 验证接口及核心业务逻辑 | — |
| 部署 | 本地 uvicorn | 开发运行 | Docker Compose、备份、认证、细粒度权限 |

MVP 阶段刻意不引入 PostgreSQL、pgvector、LangGraph 和多 Agent：初期最重要的是验证「AI 能否利用真实数据给出更好的回答」，先跑通数据闭环再升级技术组件。

## 四、数据模型

已实现（MVP）：

- `profile` — 个人档案：称呼、长期目标、偏好、更新时间
- `memories` — 长期记忆：内容、分类、来源、可信度、是否确认、时间戳
- `conversations` + `messages` — 对话：主题、用户消息、AI 回答、历史延续
- `documents` — 私人知识库：文本资料及来源文件名
- `approvals` — 操作审批：操作类型、参数、审批状态、处理时间

后续正式版本需增加：`goals`、`tasks`、`events`、`data_sources`、`sync_logs`、`audit_logs`，并给长期记忆加入有效期、冲突关系、敏感级别和失效原因。

**重要区别：记忆 ≠ 原始数据。** 导入的学习记录是原始资料；AI 总结出的偏好属于推断。正式版本应分别存储，并允许用户确认或纠正推断。MVP 已遵守：不自动把模型推断写入长期记忆。

## 五、安全边界（长期有效）

1. 审批模块只记录批准/拒绝状态，**不执行**任何文件修改、命令或消息发送（MVP 及近期阶段）。
2. 无认证：仅绑定 127.0.0.1，永不暴露公网。
3. 不自动将模型推断写入长期记忆（避免把猜测存成事实）。
4. API Key 不进前端代码、不进 Git（`.env`、`run.bat` 不提交）。
5. 正式版自动化必须有完整生命周期：分析 → 校验参数与权限 → 保存待审批 → 用户确认 → 受限执行器执行 → 记录结果与审计日志 → 反馈。不能让大模型直接拼接 Shell 命令；一次批准不等于授权所有类似操作；执行前重新检查路径、权限和文件变化。

## 六、分阶段开发与验收

### 阶段 1：MVP 基础系统（当前）
- 范围：个人档案、手动记忆、文本知识库、AI 对话、审批记录、本地演示模式。
- 状态：功能已实现，5 个 API 测试通过。
- 待办：本机启动验证（uvicorn 启动、浏览器访问、五个功能手动走一遍）。
- 实现文档：`docs/plans/phase-1-mvp.md`（待补）
- 已知局限：关键词检索非向量检索；审批不执行；非生产级隐私防护。

### 阶段 2：真正的长期记忆（下一步，优先级最高）
- 范围：自动提取记忆候选、去重、冲突检测、过期处理、用户确认、向量检索。
- 验收标准：能从历史信息中找到相关事实，展示记忆来源，允许纠错和删除。
- 实现文档：`docs/plans/phase-2-long-term-memory.md`（已创建）

### 阶段 3：个人数据接入（已实现，验收对照见 `specs/009-phase3-data-import/spec.md`）（已实现，验收对照见 `specs/009-phase3-data-import/spec.md`）
- 范围：PDF、Word、Markdown 导入；日程、任务、GitHub 项目等授权数据源。
- 验收标准：数据可增量同步、查看来源、追踪失败记录、撤销授权。
- 实现文档：`docs/plans/phase-3-personal-data-center.md`（已创建）

### 阶段 4：个人分析与建议（已实现，验收对照见 `specs/010-phase4-analysis/spec.md`）（已实现，验收对照见 `specs/010-phase4-analysis/spec.md`）
- 范围：目标、任务、行为记录和复盘机制；每日计划、每周总结、阶段性建议。
- 验收标准：每条重要建议都有数据依据、明确执行步骤和可验证的结果指标。
- 实现文档：`docs/plans/phase-4-personalization-engine.md` 等（已创建）

### 阶段 5：受控 Agent 自动化（按设计豁免，见 `specs/011-phase5-agent-exemption/spec.md`）（按设计豁免，见 `specs/011-phase5-agent-exemption/spec.md`）
- 范围：工具注册、白名单、权限校验、审批后执行、审计日志、失败恢复。
- 验收标准：未经确认的高风险操作无法执行；批准后的操作也只能在已授权范围内执行。
- 实现文档：`docs/plans/phase-5-1.3.5-reminders-*.md` 等（已创建）；执行器部分按豁免口径延后

**为什么阶段 2 优先于多 Agent**：需要的不是一个会调用很多工具的 AI，而是能长期、准确理解你的个人 AI。记忆质量、数据来源和反馈机制决定它能否持续给出适合你的建议。

## 八、工作流程约定（本文档的核心规则）

1. **每个阶段开工前**：在 `docs/plans/` 创建 `phase-N-<主题>.md`，写明目标、任务拆解、涉及文件、验收标准，然后才开始实现。
2. **实现过程中遇到错误**：每个错误（或每类错误）整理到 `docs/errors/` 下的错误文档中，记录：错误现象、原因分析、解决方案、涉及文件、日期。禁止只修复不留档。
3. **阶段完成后**：更新对应实现文档的状态与验收结果，并在本文档「分阶段开发」一节更新状态。
4. 目录结构：
   - `docs/PLAN.md` — 本文档（总体计划）
   - `docs/plans/phase-N-*.md` — 各阶段实现文档
   - `docs/errors/ERR-NNN-<主题>.md` — 错误记录（编号递增）

## 九、本机启动方式（备忘）

```powershell
# 定位到 D:\develop\VibeCodingProjects\personal-ai-os-mvp
py -3.11 -m venv .venv   # 已完成
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 启动
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
# 浏览器访问 http://127.0.0.1:8000

# 接云端模型（启动前设置环境变量）
$env:LLM_BASE_URL="https://api.openai.com/v1"
$env:LLM_API_KEY="替换成你自己的API密钥"
$env:LLM_MODEL="gpt-4o-mini"
```

首次使用顺序：填档案 → 加记忆 → 存资料 → AI 助手提问 → 测试审批。
