# 错误记录：冲突候选漏判——极性词表把频率词「每天」误当正面极性

- 日期：2026-10-11
- 阶段：阶段 2 / 迭代 03（相似度去重与冲突检测）
- 严重程度：中（核心业务规则缺陷：新旧相反偏好未被标记为冲突）

## 现象

`test_store_marks_duplicate_and_conflict` 与 `test_edit_pending_candidate_recomputes_markers` 失败：

```
assert None is not None   # conflict_with 未被标记
assert None == 1          # PATCH 编辑后重新匹配仍未标冲突
```

语料：已确认记忆「我喜欢每天早上喝咖啡」，新候选「我不喜欢每天早上喝咖啡」，期望 `conflict_with` 指向旧记忆，实际为 None。

## 原因

`app/memory_match.py` 的极性判定中，`_POSITIVE_CUES` 混入了频率词「每天」：

```python
_POSITIVE_CUES = ("喜欢", "习惯", "坚持", "每天", ...)
```

「我不喜欢每天早上喝咖啡」既命中否定（不+喜欢），又命中正面词「每天」，`_polarity()` 因此返回 0（中性），极性翻转条件不成立，冲突漏判。

更早一轮还发现过相邻问题：「不喜欢」包含正面词「喜欢」，初版只做整句包含判断也会判成中性；已通过「正面词前 2 个字符内出现否定标记则翻转」修复。

## 处理

1. 从 `_POSITIVE_CUES` 移除频率词「每天」（频率不是情感极性）。
2. 保留否定标记（不/没/别/未/戒/无）在正面词前 2 字窗口内翻转极性的逻辑。
3. 增加极性单元用例：喜欢=+1、不喜欢=-1、每天（无极性词）=0。

## 教训 / 预防

- 极性词表只放真正表达好恶/坚持的词，频率/时间副词（每天、总是、一直）不能作为极性依据；「总是」「一直在」也偏频率，后续若再出现误判应同样评估移除。
- 词法启发式必须用「正例 + 反例 + 包含反标语的正句」三类语料一起测，避免词表交叉污染。
- 该匹配只做保守提示、最终由人裁决的设计不变；阈值与词表集中为常量便于调参。
