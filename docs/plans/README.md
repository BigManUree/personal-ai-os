# plans/ — 阶段实现计划文档

每个开发阶段动手实现之前，在本目录创建对应阶段的实现计划文档：

- 命名：`phase-<N>-<短名>.md`（例如 `phase-2-long-term-memory.md`）
- 内容：目标、验收标准、改动范围（文件/接口/表）、实现步骤、设计决策
- 计划经确认后才进入实现；实现中的偏差回写到该文档
- 设计文档存在不代表功能已经实施，状态必须与源码和测试一致

`../PLAN.md` 是项目早期的总体历史记录；当前进行状态以 `../current-task.md`、`../progress.md` 和本目录中的阶段文档为准。
